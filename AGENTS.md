# AGENTS.md — Andrey AI Lab

## О проекте

Личный блог Andrey про AI-архитектуру и AI-оптимизацию бизнес-процессов. Статический сайт на чистом HTML/CSS/JS с минималистичным футуристическим дизайном, вдохновлённым фильмом «Обливион» (2013).

## Технологии

- HTML5
- CSS3 (кастомные свойства, анимации, backdrop-filter)
- Vanilla JavaScript (ES6+)
- Markdown — источник статей
- Node.js — сборка сайта и генерация RSS

Никаких фреймворков и сборщиков. Сайт работает через локальный сервер.

## Главный источник правды

**`src/articles/{slug}.md`** — единственное место для создания и редактирования статей.

Формат frontmatter:

```yaml
---
slug: nazvanie-stati
title: 'Заголовок статьи'
description: 'Краткое описание для карточки и RSS'
date: 2026-08-10
tags:
  - AI-архитектура
  - Агенты
featured: true
---
```

- `slug` должен совпадать с именем файла без `.md`.
- `featured: true` — статья отображается на главной.
- `draft: true` — статья не публикуется.
- Теги используются для фильтрации на `articles.html`.

## Критически важные правила

1. **Не редактировать вручную:**
   - `articles/{slug}/index.html`
   - `data/articles.json`
   - `rss.xml`

   Эти файлы генерируются `build.js`.

2. **После любого изменения статьи запускать сборку:**
   ```bash
   npm run build
   ```

3. **Не копировать HTML-статьи как шаблон.** Для новой статьи используй `npm run new-article` или создай `.md` в `src/articles/`.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run build` | Собрать сайт из markdown |
| `npm run new-article -- --slug ... --title ...` | Создать новую статью |
| `npm run serve` | Поднять локальный сервер без сборки |
| `npm run dev` | Собрать и поднять локальный сервер |

## Как добавить статью

1. Создать markdown-файл:
   ```bash
   npm run new-article -- --slug moya-statya --title "Моя статья" --tags "AI-архитектура" --featured
   ```
2. Отредактировать `src/articles/moya-statya.md`.
3. Запустить `npm run build`.
4. Проверить через `npm run serve`:
   - главную страницу (`/`)
   - архив статей (`/articles.html`)
   - страницу новой статьи (`/articles/moya-statya/`)
   - RSS (`/rss.xml`)

## Как обновить статью

1. Отредактировать `src/articles/{slug}.md`.
2. Запустить `npm run build`.
3. Проверить результат.

## Как изменить шаблон статьи

Редактируй `src/templates/article.html`. После изменения запусти `npm run build`, чтобы пересобрать все статьи.

Доступные placeholder-ы:

- `{{title}}`
- `{{description}}`
- `{{date}}` — ISO-дата (`YYYY-MM-DD`)
- `{{formattedDate}}` — дата в формате `DD.MM.YYYY`
- `{{tags}}` — готовый HTML с тегами
- `{{content}}` — основной контент статьи

## Структура и пути

- Header/footer подгружаются через JS (`js/components.js`). При отключённом JS они не отобразятся.
- Шаблоны `templates/header.html` и `templates/footer.html` используют placeholder `{{BASE}}`, который заменяется на `./` или `../`.
- Страницы статей используют относительные пути `../../` к корневым ресурсам.

## Стиль и дизайн

- Холодная палитра: белый, ледяной серый, бледно-голубой, угольно-чёрный, стальной, пыльный бежевый.
- Минимализм, много воздуха, скруглённые углы, парящие элементы.
- Шрифты: Inter (основной), JetBrains Mono (акценты/код).
- Анимации: particle network, typewriter, tilt-эффект карточек, glow от курсора, scroll progress, parallax.
